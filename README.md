# SymphoKnight

Jogo desenvolvido para a matéria de criação e desenvolvimento de jogos. O objetivo da demo é representar o loop de gameplay, em que o jogador "maestro" deve atacar o oponente em ritimo com a música. 


# Developer setup

Em um terminal (via SSH):

```
git clone git@github.com:Edu-Hiroshi/SymphoKnight.git
```

```
cd SymphoKnight
```

## Necessário

Godot versão 4.3 ou superior.
